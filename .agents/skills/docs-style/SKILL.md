# SKILL: Стиль документации и комментариев

## Назначение

Единые правила оформления README-файлов и комментариев в коде.

## Область

- `README.md`
- `src/opcodes/README.md`
- `examples/README.md`
- Комментарии в `src/**` и `examples/**`

## Ключевые факты

### Политика по эмодзи (обязательно)

- **Эмодзи запрещены во всём проекте**, включая исходный код и комментарии.
- **Исключение** — только файлы `README.md`, и только ограниченный перечень:
  `ℹ️`, `⚠️`, `💡`.
- Любые другие эмодзи (включая декоративные в заголовках) не допускаются.
- В `.ts`-файлах эмодзи запрещены полностью — без исключений.

Эмодзи-перечень по назначению:

| Эмодзи | Когда применять |
|--------|-----------------|
| `ℹ️` | вводная врезка «О чём этот документ» |
| `⚠️` | предупреждение (например, неканоничность `DEC`) |
| `💡` | подсказка/примечание |

### Язык

- Текст документации и комментариев — **русский**.
- Технические термины, имена опкодов, идентификаторы — латиницей.

### Структура README

- Заголовок `#`, разделы `##`, подразделы `###`.
- Справочник опкодов: `### OPCODE . 0xNN . краткое описание`.
- Врезки — блочная цитата `>`.

### Комментарии в коде

- Шапка файла: `// ===...` с именем файла и назначением.
- Секции: `// ------`.
- JSDoc (`/** ... */`) для экспортируемых функций и классов.

## Правила

- Перед коммитом проверять файлы на наличие запрещённых эмодзи.
- Не добавлять эмодзи в заголовки ради «украшения».
- При обновлении опкодов синхронизировать `src/opcodes/README.md`.
- При изменении примера синхронизировать `examples/README.md`.

## Проверка

Поиск запрещённых эмодзи (должно быть пусто, кроме `ℹ️`, `⚠️`, `💡` в `.md`):

```bash
# эмодзи в .ts (должно быть пусто)
grep -rlP '[\x{1F000}-\x{1FAFF}\x{2600}-\x{27BF}\x{2B00}-\x{2BFF}]' --include='*.ts' src examples

# инвентарь эмодзи в README (ожидаются только ℹ️ ⚠️ 💡)
grep -oP '[\x{1F000}-\x{1FAFF}\x{2600}-\x{27BF}\x{2B00}-\x{2BFF}\x{2139}]' README.md src/opcodes/README.md examples/README.md | sort | uniq -c
```

Проверка баланса код-блоков:

```bash
awk '/^```/{c++} END{print (c%2==0?"balanced":"UNBALANCED")}' README.md
```

Связанные скилы: `opcodes`, `immediate-opcodes`, `examples`.
